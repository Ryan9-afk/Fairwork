# User validation protocol

## Participants

Recruit three intended users where possible. If peers participate, label them as peers. Record participant codes only: P1, P2, P3. Do not collect names, employers, phone numbers, case details, or photographs.

## Task

Ask each participant to use synthetic details to record a shift, attach a supplied sample payment image, record a wage concern, and prepare a dossier with the telephone number excluded. Give no coaching unless the participant cannot continue.

## Law mentor review

Ask the mentor to review one synthetic construction scenario, calculation labels, dossier disclaimer, source register, and assistance checklist. Record the reviewer’s role, date, corrections requested, changes made, and unresolved questions. Do not describe the product as legally approved.
